## 3. 今回（10/25）変えたこと

### 3.1 仕組み

| 変更 | 内容 |
|---|---|
| `story.js` → `data.js` | 改名。ボタンやお知らせの文字も `engine.js` から移した（`UI`） |
| 名前の入力 | 1-1（PC）と2-4（iPhone）で入力して記録。公開ページに名前を書かない |
| 条件つきの行 | `if`・`unless`。外へ出られない日、鏡とカード、プレゼントの渡し方に使う |
| ヒントを1つずつ | 押すたびに次のヒント。最後の謎は3段階 |
| 暗号の合言葉 | 駅名を、PCの合言葉としても使えるようにした |
| 表示用に隠す | 駅名と公園名を、元に戻せる形で隠して持つ（スキップ時に駅名を表示） |
| 地図を見せるだけ | 2-2で、地図を見せながら選択肢を出す（`room: "look"`） |
| 声だけの人物 | 「ブラッキーの声」「エーフィの声」 |
| 最後の謎の枠 | 「ー」の5マスを埋めた枠を表と色で描き、答えの列に色をつける |
| なかまノート | 会った仲間ともらった言葉の一覧。まだ会っていない仲間は空らん |
| 終わりの画面から再開 | 開き直して「つづきから」を押すと、終わりの画面にもどる |

### 3.2 文章と中身

- 文章を、設計書の第10節の方針（13歳向け、1回の発言は短く）で書き直した。
- ブースターの居場所を、コンロから冷蔵庫の横に変えた（カード「ぬくぬく」）。
- サンダースは雷までの距離の計算、リーフィアは冬芽の観察にした。
- ニンフィアの言葉を「アシスト」から「リボン」に変えた。文字は光らせない。
- 外へ出られない日の道筋を足した（3-0で「今日は家の中で進める」を選ぶ）。
- 最終章をPCへ移し、問いかけ（4-4）とプレゼント（4-5）を設計書どおりにした。
- 公園名を、文章から外して「表示用に隠す」形にした。

## 7. 確認したこと・まだ確認していないこと

### 7.1 こちらで確認したこと（自動操作のブラウザ、10/25）

PC（1280×800）とiPhone 13相当の画面を、別々の記録で行き来させて確認しました。

- 正解の道筋で、PC→iPhone→PC→iPhone→PC と最後のおしまいまで進めた
- まちがいの選択肢・まちがいの入力のあと、選び直し・入れ直しができた
- ヒントが押すたびに1つずつ出て、最後のヒントはくり返し出た
- 鏡・ブースターのカード・最後の謎で、3回まちがえると救済ボタンが出て進めた
- 鏡でスキップすると、駅名が画面に出た。iPhoneの合言葉待ちのヒントでも出た
- 駅名を、PCの入力欄とタイトル画面の合言葉の両方で入れられた（ひらがな・漢字・駅つき）
- 外へ出られない日の道筋で、サンダースとリーフィアのセリフが切りかわった
- 「ただいま」を手元のiPhoneに入れても、最終章を最後まで遊べた
- 途中で開き直すと「つづきから」で再開でき、終わりの画面からも再開できた
- QRコードを読み直すと、「前回のつづきから」を選べた
- 2-2より前は、メニューに夢の部屋の地図が出なかった
- 文章に `{ }` が残らず、名前・駅名・公園名が置きかわった
- コンソールのエラーはなかった。data.js の点検も問題なし（エラー0・警告0）

## 8. お手持ちのiPhoneでの確認手順

息子さんのiPhoneでなくても、ほとんどの確認ができます。
同じiPhoneのSafariで動くためです。

1. PCで `https://kurataka123-ctrl.github.io/game/` を開き、第1部から2-2まで遊ぶ。
2. PCで `…/game/cards.html` を開き、ブラッキーのカードのQRコードをiPhoneで読む。
3. iPhoneで2-6まで進める。鏡の答えは、鏡のそばのカードに書いた駅名を入れる。
4. PCの終わりの画面で「エーフィに話しかける」を押し、駅名を入れて2-7を進める。
5. iPhoneに「まどのそと」を入れ、第3部を進める。家の中で「着いた」を押してよい。
6. PCの終わりの画面で「家に帰ってきた」を押し、「ただいま」を入れて最後まで進める。
7. 途中で、ほかのアプリに切りかえてからもどる。ページを開き直す。
8. 入力のとき、キーボードで画面が隠れないか見る。
9. 終わったら、PCとiPhoneで `…/game/index.html?debug` を開き、🛠 →「記録を消す」。

息子さんのiPhoneでは、次の2点だけ確認してください。

- 「設定」→「一般」→「情報」の iOS のバージョン（古すぎないか）
- QRコードを読むと開けるか（確かめたら、すぐに記録を消す）
