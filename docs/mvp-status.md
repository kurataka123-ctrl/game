## 4. 引き継ぎ書から変えた点・判断した点

### 4.1 ニンフィアの言葉を「パーティー」から「アシスト」に変えた（仮）

引き継ぎ書の8つの単語候補では、「メリークリスマス」を作れません。
各単語から1文字ずつ取り出すと、「ス」が1つ足りなくなります。

- 「リ」を含むのは、スノークリスタルとミステリーだけ。2つとも「リ」に使う。
- すると「ス」を出せるのは、スピードだけになる。「ス」は2つ必要。
- 残るパーティーとシャワーには「ス」がない。

シャワーズの「シャワー」は決定事項なので、ニンフィアの言葉を変えました。
「アシスト」は、仲間と協力する場面に合わせた仮案です。
紙折りパズルを作るときも、この組み合わせなら1語1文字で成り立ちます。

### 4.2 ③エーフィと④ブラッキーを入れ替えた

最初の版では、③ブラッキー・④エーフィの順でした。
しかし④でエーフィが「ブラッキーと連絡が取れない」と話すため、順番が不自然でした。
そこで、③エーフィ → ④ブラッキーの順に入れ替えました。

- ③：エーフィが、ブラッキーが夢の部屋を見に行ったまま帰らないと話す。
- ④：暗い部屋でリングの光を調べると、ブラッキーの声が少しだけ聞こえて途切れる。
- その後、エーフィの力で部屋が明るくなり、自分の部屋だと気づく。

④でも、ブラッキー本人には会えません（光と声だけ）。
ブラッキーには、QRコードを読んだあと、iPhoneで初めて会えます。
言葉「ミステリー」も、iPhoneでブラッキーからもらいます。

### 4.3 鏡の答え（駅名）は暗号にした

ゲームのページは、URLを知っている人なら誰でも中身を読めます。
駅名は、読めない形（暗号）で `story.js` に書きました。
鏡にはカタカナで書く予定ですが、ひらがな・漢字などでも正解にしています。
息子さんがページの中身をのぞいても、答えが分からない効果もあります。

公園の名前（青葉の森）は、リーフィアの話に合うため、そのまま書きました。

### 4.4 プレゼントは、おうちの人が直接わたす

「メリークリスマス」を入力すると、イーブイが次のように頼みます。
「プレゼントは、おうちの人にあずけてある。『メリークリスマス』と言ってみて」。
家に帰ってからでも、その場でも渡せる文章にしています。

### 4.5 進行不能を防ぐ工夫

| 場面 | 工夫 |
|---|---|
| シャワーズのぬいぐるみ | 「見つからない」を選ぶと、窓のほうと教えてから先へ進む |
| 鏡の文字 | ヒントあり。3回まちがえると「どうしてもわからない」で進める |
| ブースター | 台所にカードを置かなくても、クイズだけで進める |
| 駅 | 駅の掲示物は使わない。どこでも解けるクイズにした |
| 公園 | 葉っぱが見つからなくても進める |
| 最後の謎 | ヒントあり。3回まちがえると「答えを教えて」で進める |
| ページの開き直し | 記録があれば「つづきから」をいちばん上に出す |
| QRコードの読み直し | 「前回のつづきから」をいちばん上に出す |

- 3回まちがえると「どうしてもわからない」が出て、押すと先へ進めた
- 最後の答えは「メリークリスマス」「めりー・くりすます！」「Merry Christmas」で正解
