**PC→iPhone→PC→iPhone→PC と行き来して、最初から最後まで遊べます。**

### 3.4 1-3 花畑の流れ

1. 和室（氷の洞窟）側のふすまから入ると、ニンフィアが手伝いを頼む。
2. 花畑を歩いて、仲間を集める（順番は自由）。
   - リザードン：日だまりで昼寝している。話しかけると仲間になる。
   - ピッピ：切り株の陰。一度かくれるので、ニンフィアに頼むと、一緒に来てくれる。
   - 友達3人：平たい大岩のそばで遊んでいる。だれに話しかけても3人とも仲間になる。
   - キバゴ：氷のかたまり（冷蔵庫）のそば。任意（仲間にしなくても進める）。
   - 花畑の住人3匹（ミツバチ・テントウムシ・チョウチョ）：戦いのヒントをくれる。
3. リザードン・ピッピ・友達がそろってから、ニンフィアに話しかけると戦いになる。
   足りないときは、ニンフィアが次に探す場所を教えてくれる。
4. 戦い（今は【仮】の選択肢）に勝つと、こおった花が元にもどり、ろうか側の門が開く。

3. iPhoneで2-6まで進める。鏡の答えは、鏡のそばのカードに書いた駅名を入れる。
4. PCの終わりの画面で「エーフィに話しかける」を押し、駅名を入れて2-7を進める。
5. iPhoneに「まどのそと」を入れ、第3部を進める。家の中で「着いた」を押してよい。
6. PCの終わりの画面で「家に帰ってきた」を押し、「ただいま」を入れて最後まで進める。
7. 途中で、ほかのアプリに切りかえてからもどる。ページを開き直す。
8. 入力のとき、キーボードで画面が隠れないか見る。
9. 終わったら、PCとiPhoneで `…/game/index.html?debug` を開き、🛠 →「記録を消す」。

息子さんのiPhoneでは、次の2点だけ確認してください。

- 「設定」→「一般」→「情報」の iOS のバージョン（古すぎないか）
- QRコードを読むと開けるか（確かめたら、すぐに記録を消す）
