## 3. 今回（10/26）変えたこと：戦闘（作る順番4）

### 3.1 戦いの流れ

| 順 | 場面 | 戦う組（操作するキャラ） | 相手 | 勝ち方【仮】 |
|---|---|---|---|---|
| 第1戦 | `sylveon_battle1` | ポケモン組（イーブイ） | よろい雪だるま（氷のよろい） | てだすけで、リザードンのほのおを2倍にする |
| 第2戦 | `sylveon_battle2` | 人間組（主人公） | ころがり雪だるま（転がって暴れる） | 力アップ中に「つかまえる」 |
| 決め技 | `sylveon_finale` | 2組そろって（主人公） | 2体とも | 「みんなでいっせいに」を選ぶ |

- 戦いの前に、雪だるまが2体現れる場面（`sylveon_battle`）を置きました。
- 決め技では、ニンフィアのリボンが仲間の列をつなぎ、ニンフィアも一緒に戦います。
- 勝つと、ニンフィアから言葉「リボン」をもらい、花畑の地図にもどります（今までどおり）。

### 3.2 決まり（設計書 第5節のとおり）

- 操作するのは各組の1人だけです。ほかの仲間は、さくせんのとおりに自動で動きます。
- ハートは組で共通の3つです。数値は固定で、乱数は使いません。
- 2ターンに1回、ふぶきが来て、ハートが1つ減ります（第1戦・第2戦）。
- 効かない技を出すと、理由が分かる文が出ます（例：「氷のよろいに、はね返された！」）。
- 負けたら、ニンフィアがヒントを出します。その戦いの最初から、ハート3つでやり直します。
- キバゴを仲間にしていないと、ポケモン組は3人で戦います（それでも勝てます）。
- 人間組の技と自動で動く決まりは、設計書の表のとおりです（友達1〜3）。

### 3.3 【仮】で決めたこと（見てほしい点）

設計書で未決だった点を、次のように仮に決めました。どれも `data.js` で差し替えられます。

| 未決の点 | 仮に決めたこと |
|---|---|
| 雪だるま2の特徴と止め方 | 転がっている間は、攻撃が当たらない。「つかまえる」で止める（いきおい2）。ひとりの力（1）では止めきれない。友達2の技で力が上がっている間（+1）なら止まる |
| 操作するキャラのコマンド | イーブイ：たいあたり・てだすけ。主人公：雪玉を投げる・つかまえる |
| 第1戦の考えどころ | 氷のよろいは、ほのお2回分でとける。1回分だと、ターンの終わりに固め直される。てだすけで2倍にすると、一度にとける |
| てだすけと友達2の技の分け方 | てだすけ：次に動く仲間1人の技を2倍。ぶんぶんハローYouTube：全員の攻撃を+1（2ターン） |
| リザードンとピッピのさくせん | リザードン：毎ターン ほのお。ピッピ：ハートが2以下なら月の光、それ以外は はたく |
| キバゴの技とさくせん | 毎ターン ひっかく（氷のよろいには、はね返される） |
| 決め技を選ぶキャラ | 主人公。ほかの2つのコマンドは、理由を聞いて選び直す（ハートは減らない） |
| 雪だるまの名前 | よろい雪だるま・ころがり雪だるま |

第1戦の考えどころは、設計書の推奨「てだすけを受けたときだけ、決め手の技が届く」に合わせました。

`?debug` の「戦いの点検」で、自動で調べた結果です。

| 戦い | 最短で勝てるターン | 負けることがあるか |
|---|---|---|
| 第1戦 | 1ターン（てだすけ） | ない（ピッピの月の光で、回復が追いつく） |
| 第2戦 | 2ターン（2ターン目につかまえる） | ある。2・4ターン目のどちらでもつかまえないと、4ターン目に負ける |
| 決め技 | 1ターン（みんなでいっせいに） | ない |

- 第1戦は負けない代わりに、3ターン目と5ターン目に、ニンフィアがヒントを出します。
- 第2戦は、3回負けると「ニンフィアに手伝ってもらう」ボタンが出て、先へ進めます。
- 気になる点：今の案では、キバゴは第1戦で役に立ちません。
  仲間にした手ごたえを出すなら、キバゴの技を決める必要があります。

### 3.4 PCだけで使う公式のイラスト

- PCで `index.html` を直接開いたときだけ、`pc-images` フォルダの画像を使います。
- 公開したページ（iPhone）とメッセージ画面では使いません。画像を読みにもいきません。
- 使うのは、会話の画面・歩けるマップ・戦い・なかまノート・言葉をもらう画面です。
- 画像がないキャラクターは、今までどおり絵文字です。
- `pc-images/` は `.gitignore` で除外し、リポジトリには入れません。
- 使い方と画像の名前は、README の7章にまとめました。
- 設計書の第11節（「公式の画像は使わない」）とは、扱いが変わります。設計書の更新が必要です。

- 戦い中のヒント（第1戦の3・5ターン目、第2戦の3ターン目）と、負けたときの2つ目のヒント

### 3.6 仕組み

| 変更 | 内容 |
|---|---|
| `BATTLES`・`MOVES`（data.js） | 戦いの決まり・技・数値・さくせん・戦いの中のセリフ |

### 4.4 1-3 花畑の流れ

1. 和室（氷の洞窟）側のふすまから入ると、ニンフィアが手伝いを頼む。
2. 花畑を歩いて、仲間を集める（順番は自由）。
   - リザードン：日だまりで昼寝している。話しかけると仲間になる。
   - ピッピ：切り株の陰。一度かくれるので、ニンフィアに頼むと、一緒に来てくれる。
   - 友達3人：平たい大岩のそばで遊んでいる。だれに話しかけても3人とも仲間になる。
   - キバゴ：氷のかたまり（冷蔵庫）のそば。任意（仲間にしなくても進める）。
   - 花畑の住人3匹（ミツバチ・テントウムシ・チョウチョ）：戦いのヒントをくれる。
3. リザードン・ピッピ・友達がそろってから、ニンフィアに話しかけると戦いになる。
   足りないときは、ニンフィアが次に探す場所を教えてくれる。
4. 戦いに勝つと、こおった花が元にもどり、ろうか側の門が開く。
   （10/25 夜は選択肢の仮。10/26 に選択式のバトルにした。3節）

## 5. 10/25（作る順番1・2）で変えたこと

| 変更 | 内容 |
|---|---|
| `story.js` → `data.js` | 改名。ボタンやお知らせの文字も `engine.js` から移した（`UI`） |

| 終わりの画面から再開 | 開き直して「つづきから」を押すと、終わりの画面にもどる |
